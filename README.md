## Vibe code you can trust.

You describe it. The agent builds it. A few prompts later, your idea is alive.

The prototype looks great. The demo works.
But you're about to put it in someone else's hands.

That's when “the agent said it's done” stops being enough.

You want to know what was tested. What got reviewed. What still needs fixing.

**Keep the flow. Build the confidence to ship.**

---

## Build with OH. Ship with confidence.

OH brings the care of a thoughtful engineering team to your vibe coding.
A clear plan. Your project checks. A fresh AI reviewer for every task.

### Propose · Give your idea room to grow.

Bring the rough thought. Explore the possibilities. Shape what you want to build.

### Design · Know what “done” looks like.

Turn the idea into technical docs, tasks in the right order, and clear acceptance checks.

### Deliver · Get code you can stand behind.

Agents build one approved task at a time. Your checks run. A fresh, independent AI reviewer examines the result.

Blockers go back for fixes. OH pauses if they remain unresolved.
Only reviewed work gets committed.

**You see what was checked. You decide what ships.**

## Try OH

Works with **Claude Code** and **Codex**, through your existing subscription.
No separate API billing.

**Claude Code**

```sh
claude plugin marketplace add pmoreiracc/o-harness#dist
claude plugin install o-harness@o-harness
```

**Codex**

```sh
codex plugin marketplace add pmoreiracc/o-harness --ref dist
codex plugin add o-harness@o-harness
```

Open a new session in your project. Bring an idea:

```text
/oh-propose Add search to my notes app. Keep it simple.
```

In Codex, use `$oh-propose`. First use sets up your project and checks; run the proposal again after setup.
Planning leaves your code untouched. Build when you're ready with `oh-deliver`.

<sub>macOS, Linux or 64-bit Windows 11 (preview) · Python 3.12+ · Git</sub>
